# ProxyDesk — Портативный менеджер прокси, локального шлюза и пользовательского DNS

**ProxyDesk** — портативное приложение на Go со встроенным веб-интерфейсом (`go:embed`) и базой SQLite (`modernc.org/sqlite`, сборка с `CGO_ENABLED=0`) для Windows 10/11 x64 (с кроссплатформенным ядром для Linux и macOS).

---

## 1. Статус функций (после пакета STABILIZATION-01)

В соответствии с инженерными требованиями функции классифицированы по четырём статусам:
- **реализовано и проверено** — выполнено и подтверждено исполняемыми тестами в среде разработки;
- **реализовано, но не проверено** — код и тесты написаны в полном объёме, но требуют прогона компилятором Go / на раннере Windows CI (так как в офлайн-контейнере разработки отсутствует бинарник `go`);
- **частично реализовано** — базовая функциональность создана с известными ограничениями;
- **отсутствует** — не входит в пользовательский выпуск (выделено в отдельный привилегированный этап).

| Модуль / Возможность | Статус | Примечание |
| :--- | :--- | :--- |
| **Схема SQLite (`001_init.sql`), миграции, дедупликация и горячий бэкап `VACUUM INTO`** | **реализовано и проверено** | Проверено на движке `SQLite 3.40.1` (включая `CHECK`/`FOREIGN KEY` ограничения, пакетную вставку `5 000` прокси в `WAL`-режиме и валидацию версии бэкапа). |
| **Веб-интерфейс (`web/dist/*`), словарь локализации (`RU_STRINGS`) и `DecisionTrace` карточка** | **реализовано и проверено** | Проверено модульными тестами `node --test web/test_ui.mjs` (`Node.js v18.20.4`). Пользовательские строки вставляются через `textContent` (`setSafeText`), однако 3 модульных теста не заменяют комплексный браузерный аудит безопасности. |
| **Координатор жизненного цикла (`internal/app`), запуск `HTTP`/`SOCKS5`/`DNS UDP+TCP` слушателей и планировщика** | **реализовано, но не проверено** | Полностью интегрировано в `cmd/proxydesk/main.go` и `internal/app/app.go` (включая отображение реальных `bound_addr` и ошибок `bind_errors`). Проверяется через `go test ./...` и Windows CI. |

| **DNS-прокси: проверка `ID`/`QR`/`Opcode`/`Question`, `TTL=0`, `SOA Negative TTL` (RFC 2308), `CNAME` и `UDP→TCP`** | **реализовано, но не проверено** | Реализовано в `internal/dns/server.go` с автоматической очисткой кэша при смене правил/групп. Проверяется через `go test ./internal/dns`. |

## 2. Воспроизводимые команды сборки, проверки и запуска

### Шаг 1. Формирование и проверка подлинного `go.sum` через `GOSUMDB`

```bash
go mod tidy
go mod verify
```

### Шаг 2. Статический анализ, модульные, E2E и race-тесты

```bash
go vet ./...
go test -v ./...
CGO_ENABLED=1 go test -race ./...
go test -fuzz=FuzzNormalizeProxyLine -fuzztime=10s ./internal/parsers
node --test web/test_ui.mjs
```

### Шаг 3. Сборка портативного `.exe` для Windows 10/11 x64 (`CGO_ENABLED=0`)

```bash
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o dist/proxydesk.exe ./cmd/proxydesk
```

### Шаг 4. Запуск

```bash
./dist/proxydesk.exe --portable
```

Поддерживаемые флаги:
- `--portable` — хранить данные в папке `data/` рядом с исполняемым файлом;
- `--data-dir <путь>` — явный путь к папке данных (приоритет над `--portable`);
- `--no-open-browser` — не открывать браузер при старте;
- `--listen 127.0.0.1:18443` — адрес локального веб-интерфейса и API.
